The Roadmap: architecture

Content flows from JSON through a verifier into a static Next.js site. Progress never leaves the browser.

Notes

  • The verifier is the only thing that writes statuses. Nobody sets APPROVED except Taha.
  • next.config.ts builds normally by default; DEPLOY_TARGET=static switches to a static export with an optional BASE_PATH.
  • Every component reads progress through ProgressStore, so accounts or a database can be added by writing one more class.
